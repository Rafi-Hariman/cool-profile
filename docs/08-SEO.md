# SEO Requirements

## Metadata

The root layout (`app/layout.tsx`, App Router) defines:

- `metadataBase`: `https://rafihariman.my.id` (production domain)
- title default: `Rafi Hariman — Frontend Developer Portfolio`
- title template: `%s — Rafi Hariman`
- description: concise professional description
- Open Graph metadata (with generated `opengraph-image`, 1200×630)
- Twitter/X metadata
- canonical URL (from `metadataBase`)

Use Next.js Metadata API (`export const metadata` / `generateMetadata`).

---

# Language

The site content is English (`<html lang="en">`). No multilingual setup.

---

# Open Graph

Professional preview when shared. `og:title`, `og:description`,
`og:type: website`, `og:url`, `og:image` (1200×630, generated by
`app/opengraph-image.tsx`).

---

# Sitemap

`app/sitemap.ts` generates sitemap.xml (single homepage today; grows with
routes). `lastModified` uses a stable date, not build time.

---

# Robots

`app/robots.ts` generates robots.txt allowing all crawlers and pointing to
the sitemap. Scratch routes (`/mobile`, `/new-page`) are `noindex` via their
own route metadata.

---

# Structured Data

Schema.org JSON-LD in the root layout:

- `Person`: name (`Rafi Hariman`), alternateName (full name), url,
  jobTitle, worksFor, knowsAbout, sameAs (social profiles).
- `WebSite`: name, url, inLanguage.

---

# Semantic Content

Meaningful headings (single h1 = name). Descriptive links — never "Click
here"; prefer "View project case study" / "GitHub profile".

---

# 404

Custom `app/not-found.tsx` preserving the design language: quiet, on-brand,
with a link back home.

---

# URLs

Clean URLs. One-page portfolio today (`/`); future articles may live under
`/articles/…`.

---

# Speed Insights

Vercel Speed Insights is enabled via `<SpeedInsights />` in the root layout
(`@vercel/speed-insights/next`).
